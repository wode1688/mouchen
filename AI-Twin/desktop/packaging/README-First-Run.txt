AI替身 Windows 便携测试版

1. 将 ZIP 完整解压到一个固定文件夹；不要只把 Mouchen.exe 单独复制出来。
2. 双击 Mouchen.exe。
3. 首次运行会显示“服务地址、用户名、密码、邀请码”，可选择登录或创建账号。
4. 服务地址必须由服务提供方告知；远程地址必须使用 HTTPS。
5. 本安装包不包含账号、密码、访问令牌、API 密钥或任何用户数据库。
6. 登录后再逐项选择允许AI替身了解的信息；未授权前不应采集。
7. 如需开机启动，请登录后在“设置”中启用。移动或删除程序文件夹后需要重新启用。

本地数据目录：%LOCALAPPDATA%\Mouchen\Desktop
卸载：先在设置中关闭开机启动，再退出AI替身并删除程序文件夹。
