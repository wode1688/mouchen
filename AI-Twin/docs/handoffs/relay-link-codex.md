# 手机与电脑本地处理接通

- Issue: https://github.com/wode1688/mouchen/issues/3
- 工具：Codex；主集成分支 `ai/codex/relay-link`
- 起点：`1d42bdb79cbe87e1b41875d74aef532403f04bff`
- 分工：主执行者负责 `relay/` 协议、持久桥接器、集成与文档；backend 执行者负责业务导入、规则模式和电脑启动；android 执行者负责手机界面、加密队列和同步；build 执行者负责隔离构建与审查。各用独立 worktree。

## 本次变更

新增 `ai-twin.sync/v1` 协议和电脑桥接器。收件先持久保存，再确认中转；业务导入经认证回环接口完成；回执保留至手机确认。处理失败、回执过期、重复请求、内容冲突和来源不匹配均有明确行为。收到的文件不执行，非本协议文件只归档。

## 验证

桥接器首轮使用项目锁定的业务依赖执行 `python -m unittest discover -s tests -v`，32 项通过（原 22 项加新增 10 项）。新增测试覆盖真实中转 API 下的往返、后端离线和重启、云端回执过期、接收端保存失败、幂等处理、冲突隔离及来源验证。

## 集成检查点

本记录的首次提交只包含主执行者实现。后端、Android、构建结果及实际运行验证将在集成后补充；不能从这份检查点推断手机真机已经安装或测试。当前代码提交号以 Git 历史为准。
