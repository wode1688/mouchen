# Android：电脑本地处理模式

此入口与原后端账号入口分开。安装后打开 **AI替身 · 电脑处理**；也可以从原登录页面选择“使用电脑本地处理”。不需要登录原业务后端。

## 连接和日常使用

1. 在“连接设置”导入管理员给手机生成的私密 JSON 配置，或填写 HTTPS 中转地址、手机设备名称、处理电脑设备名称及手机令牌。令牌需属于填写的手机设备，电脑需在中转服务登记。
2. 点击“保存并启用”。导入文件只填入表单，不会自动启用。配置保存在 Android Keystore 保护的本机存储，不进入同步消息。
3. 填写目标及领域，点击发送目标。目标在电脑保存成功后出现在列表。
4. 手动填写记录，或通过 Android 的文字分享菜单选择此入口。检查文本；若确为本人遇到的真实问题，勾选相应选项，使用与目标相同的领域，再点击“确认发给电脑”。分享内容不会自动发送。
5. 电脑保存并按本地规则处理后回传目标和建议。未命中证据规则时可能没有建议，请求仍会显示“电脑已处理”。建议可以反馈“采纳”或“不适用”。

电脑应运行配套中转桥接和本地业务处理程序。此入口不启用旧模式的后台采集、语音转写或旧后端模型调用，也不导入旧账号的记录。

## 同步与保留

- 点击“立即同步”可以主动收发。此页前台约每 30 秒同步，后台使用 WorkManager 的 15 分钟周期，实际执行受 Android 网络、电量和后台限制影响。
- “暂停同步”保留本机排队记录，阻止后续传输；已暂存在云端的内容仍可由电脑接收。恢复后继续处理。
- 上传完成显示“云端暂存，等待电脑回执”，不会提前标记完成。电脑离线超过 24 小时，手机会用新的云传输编号重传，业务消息编号保持不变。
- 手机核对文件大小、SHA-256、来源电脑、请求编号和操作类型，然后事务保存电脑记录与收据，最后确认云端接收。应用退出或网络中断后的重放不会重复应用已完成请求。
- 电脑回执按生成时间合并；旧快照不覆盖更新记录。切换服务器、手机或电脑名称使用不同记录分区，原记录保留在设备上。
- 本机使用独立 SQLCipher 数据库。云端只临时保存传输文件；链路为 HTTPS，当前文件协议不是端到端加密。

## 公开配置格式示例

```json
{
  "url": "https://relay.example.com",
  "device_id": "phone-a",
  "token": "REPLACE_WITH_PRIVATE_DEVICE_TOKEN",
  "targets": ["computer-a"]
}
```

也兼容旧文件的 `device` 字段和新文件的 `peer_device_id`。旧文件未包含目标时，必须在表单补全。不要把真实配置提交到 Git。

## 验证

- JVM：`gradle testPrivateAlphaDebugUnitTest`；协议身份、操作、严格类型、容量、重试语义和配置隔离测试位于 `app/src/test/java/com/mouchen/app/relay/`。
- APK：`gradle assemblePrivateAlphaDebug`。
- 设备：`gradle connectedPrivateAlphaDebugAndroidTest`；事务收据、重复、分区和旧快照测试位于 `app/src/androidTest/java/com/mouchen/app/relay/`。需要连接测试设备或启动模拟器。

本地使用 JDK 17、Android SDK 36、Build Tools 35.0.0、Gradle 8.11.1。设备测试和真实手机授权/后台调度应单独核实，不以 JVM 测试或 APK 编译成功代替。
